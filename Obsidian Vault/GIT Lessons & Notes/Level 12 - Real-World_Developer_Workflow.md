## The complete journey

**Diagram — From an assigned issue to production**

`Issue assigned → Pull latest main → Create branch feature/login → Write code → Run local tests → git status → git add → git commit → git push → Open Pull Request → CI pipeline runs → Code review — changes requested → Push update → CI runs again → Approved → Merge → Deploy to Staging → Smoke tests → Deploy to Production`

Every arrow in that diagram is something you've now learned individually. This is simply all of it, in the order a professional developer actually experiences it, dozens of times a week.

## Capstone: FAi Login Service

Time to prove it. You're assigned a real-feeling task: add email validation to the login API of a fictional project, "FAi Login Service". You'll make the decisions at each step — choosing wrong will explain exactly why, without penalty.
