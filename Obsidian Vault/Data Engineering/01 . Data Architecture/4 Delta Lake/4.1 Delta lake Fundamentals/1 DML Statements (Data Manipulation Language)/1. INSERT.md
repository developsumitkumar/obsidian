 **— Add New Rows

### What is INSERT?

`INSERT` means:

> **Add new records to a table without changing the existing records.**

Suppose our Silver Delta table currently contains:

```
transaction_id   date         category   amount
------------------------------------------------
101              2026-09-18   Food       500
102              2026-09-18   Travel     800
103              2026-09-19   Shopping   1200
```

Today's Bronze data contains a new transaction:

```
104              2026-09-20   Food       700
```

We can insert it:

```
INSERT INTO silver_transactions
VALUES (104, '2026-09-20', 'Food', 700);
```

Silver becomes:

```
101   2026-09-18   Food       500
102   2026-09-18   Travel     800
103   2026-09-19   Shopping   1200
104   2026-09-20   Food       700   ← NEW
```

Nothing happened to rows `101–103`.

In Spark you will often see this expressed as an **append**:

```
new_data.write \
    .format("delta") \
    .mode("append") \
    .save(silver_path)
```

Conceptually:

> **Append the new rows to the existing table.**

---

### But there's a problem

What if tomorrow the source sends transaction `104` again?

Blindly inserting/appending it could produce:

```
104   Food   700
104   Food   700
```

Now you have a duplicate.

Or perhaps `104` already exists but its amount changed:

```
Existing:
104   Food   700

Incoming:
104   Food   900
```

`INSERT` alone doesn't express:

> "If it exists, update it; otherwise insert it."

That's one reason **MERGE** becomes important in incremental pipelines.

---

### Interview answer

> **INSERT is a DML operation used to add new rows to a table without modifying existing rows. In a data pipeline, it is suitable when incoming data is known to contain only new records. For append-only workloads, such as event logs, we can append new records directly. However, if incoming data may contain updates to existing business keys, blindly inserting can create duplicates, so an upsert using MERGE is usually more appropriate.**
