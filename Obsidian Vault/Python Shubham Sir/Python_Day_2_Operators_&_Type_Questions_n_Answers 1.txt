Python – Day 2: Operators & Type Conversion
1) Arithmetic Operators (Math Operations)

Definition: Used to perform mathematical calculations.

| Operator | Meaning                          | Example   | Output     |
| -------- | -------------------------------- | --------- | ---------- |
| `+`      | Addition                         | `10 + 5`  | `15`       |
| `-`      | Subtraction                      | `10 - 5`  | `5`        |
| `*`      | Multiplication                   | `10 * 5`  | `50`       |
| `/`      | Division (float)                 | `10 / 3`  | `3.333...` |
| `//`     | Floor Division (ignores decimal) | `10 // 3` | `3`        |
| `%`      | Modulus (remainder)              | `10 % 3`  | `1`        |
| `**`     | Exponent (power)                 | `2 ** 3`  | `8`        |

# Shopping example
apple_price = 20
qty = 3
total_cost = apple_price * qty
print("Total Cost =", total_cost)   # 60

# Salary example
monthly_salary = 50000
annual_salary = monthly_salary * 12
print("Annual Salary =", annual_salary)   # 600000

2) Comparison Operators (Decisions)

Definition: Used to compare two values. Always return True or False.

| Operator | Meaning          | Example    | Output  |
| -------- | ---------------- | ---------- | ------- |
| `==`     | Equal            | `10 == 5`  | `False` |
| `!=`     | Not equal        | `10 != 5`  | `True`  |
| `>`      | Greater than     | `10 > 5`   | `True`  |
| `<`      | Less than        | `10 < 5`   | `False` |
| `>=`     | Greater or equal | `10 >= 10` | `True`  |
| `<=`     | Less or equal    | `5 <= 10`  | `True`  |

# Age check
age = 18
print(age >= 18)   # True (eligible to vote)

# Password check
password = "admin"
print(password == "admin")   # True

3) Logical Operators (Conditions)

Definition: Used to combine multiple conditions.
| Operator | Meaning                      | Example              | Result |
| -------- | ---------------------------- | -------------------- | ------ |
| `and`    | True if both are True        | `(5 > 2 and 10 > 5)` | True   |
| `or`     | True if at least one is True | `(5 > 10 or 10 > 5)` | True   |
| `not`    | Reverses result              | `not (5 > 2)`        | False  |

# College admission example
marks = 75
age = 17
print(marks > 60 and age >= 17)   # True

# Movie ticket example
is_student = True
has_id_card = False
print(is_student or has_id_card)   # True

4) Type Conversion (Changing Data Types)

Definition: Converting one data type into another.
| Function  | Meaning            | Example        | Result |
| --------- | ------------------ | -------------- | ------ |
| `int()`   | Convert to integer | `int("10")`    | `10`   |
| `float()` | Convert to decimal | `float("3.5")` | `3.5`  |
| `str()`   | Convert to string  | `str(25)`      | `"25"` |

# Age example
age = input("Enter your age: ")   # input is string
age = int(age)   # convert to integer
print("Next year you will be", age + 1)

# Marks example
marks = 75.5
print("Marks in string:", str(marks))  # "75.5"

Notes / Rules

Division / always gives float, even if numbers are integers.

Floor division // ignores decimals.

Modulus % is very useful for checking divisibility.

Input values are always string, must convert using int() / float() before math.

and requires both conditions True.

or requires at least one condition True.

✅ Do’s and Don’ts

Do’s
✔ Use int() or float() before arithmetic with inputs.
✔ Use % operator for checking even/odd or divisibility.
✔ Use parentheses () for clarity in complex conditions.

Don’ts
❌ Don’t add int and str directly → causes error.

print("Age = " + 25)   # ❌ Error
print("Age = " + str(25))  # ✅ Correct


❌ Don’t forget that / gives float. If you need only whole number → use //.
❌ Don’t compare strings and numbers → "10" == 10 is always False.
